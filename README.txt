# Traditional RAG Chatbot

A Traditional Retrieval-Augmented Generation (RAG) chatbot built from scratch.

## Tech Stack

- Python
- FastAPI
- Sentence Transformers
- Qdrant
- xAI / Grok
- PyMuPDF

## Current Pipeline

PDF
↓
Text Extraction
↓
Text Cleaning
↓
Chunking
↓
Metadata
↓
Embeddings
↓
Qdrant
